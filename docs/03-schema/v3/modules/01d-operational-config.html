Operational Config

Deployment-time configuration, per-user preferences, and public holidays — the three knobs that change hospital behaviour without a code deploy.

Slice 1D contents — being added one table at a time
  1. system_config — deployment-level key-value settings (auth policy, billing, integration, …)  signed off
  2. user_preferences — per-user UI + notification preferences; 1:1 extension of users (shared PK)  signed off
  3. holidays — hospital closure dates by type (national / state / local)  under review

1. system_config mutable L1 audit L3 audit soft-delete

Deployment-level key-value settings read by the app at runtime. Values are jsonb so a single column holds integers, booleans, strings, arrays, and objects without type coercion. Flyway seeds the defaults; admin edits create a new version of the row via the optimistic-lock counter.

2. user_preferences mutable L1 audit L3 audit soft-delete

Per-user UI and notification preferences. Strict 1:1 extension of users — user_id is both the primary key and the foreign key (shared PK pattern, same as doctor_profiles). A row is created lazily: only when a user explicitly saves preferences different from the app defaults. If no row exists, the app falls back to system defaults.

Columns (table-specific; uniform block also present)

Shared-PK pattern: user_id is BOTH the primary key AND the foreign key to users(id). No separate surrogate id.

3. holidays mutable L1 audit L3 audit soft-delete

Hospital closure dates — used by the appointment slot generator to skip non-working days and by payroll / attendance modules for leave calculations. Renamed from v2's tenant_holidays (tenant_ prefix and tenant_id column dropped for single-tenant deployment). One row per actual date; no recurrence logic — admin inserts a new row for each calendar year.

Columns (table-specific; uniform block also present)
ColumnTypeNullConstraintDefaultComment
iduuidNOPKuuidv7()Surrogate primary key
holiday_datedateNOUNIQUE—The actual calendar date. UNIQUE: a date cannot be declared a holiday twice.
nametextNOCHECK length 2–120—Display name (e.g. Pongal, Republic Day)
holiday_typetextNOCHECK IN (…)—Gazette classification: national | state | local
descriptiontextYES——Optional note (e.g. "Hospital closed for building maintenance")

+ the 7 uniform audit + soft-delete columns.

Constraints & Indexes

  • uq_holidays_date — UNIQUE (holiday_date)
  • chk_holidays_name_len — CHECK char_length(name) BETWEEN 2 AND 120
  • chk_holidays_type — CHECK holiday_type IN ('national','state','local')
  • ix_holidays_year — INDEX (holiday_date) WHERE deleted_at IS NULL  — appointment slot generator queries by year range
Triggers
