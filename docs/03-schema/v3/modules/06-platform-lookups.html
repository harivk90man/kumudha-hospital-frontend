1. allergies_lookup mutable L1 audit L3 audit soft-delete

Standard allergy catalogue. Flyway seeds common allergens; admin can add hospital-specific entries. Referenced by patient_allergies.allergy_id in Module 07.

Columns (table-specific; uniform block also present)
ColumnTypeNullConstraintDefaultComment
iduuidNOPKuuidv7()Surrogate primary key
allergy_codetextNOUNIQUE, CHECK length 2–40—Short machine code in SCREAMING_SNAKE (e.g. PENICILLIN, PEANUTS, LATEX)
allergy_nametextNO——Display name shown in UI and printed on prescription
categorytextNOCHECK IN (…)—drug | food | environmental | other
descriptiontextYES——Clinical note — cross-reactivity warnings, examples of related substances

+ the 7 uniform audit + soft-delete columns. Flyway-seeded rows have created_by = NULL.

Constraints & Indexes
  • pk_allergies_lookup — PRIMARY KEY (id)
  • uq_allergies_lookup_code — UNIQUE (allergy_code)
  • chk_allergies_lookup_code_len — CHECK char_length(allergy_code) BETWEEN 2 AND 40
  • chk_allergies_lookup_category — CHECK category IN ('drug','food','environmental','other')
  • ix_allergies_lookup_category — INDEX (category) WHERE deleted_at IS NULL
Triggers
  • tr_allergies_lookup_bu_touch — BEFORE UPDATE → fn_touch_updated()
  • tr_allergies_lookup_au_audit — AFTER INSERT/UPDATE/DELETE → fn_audit_row()

2. chronic_conditions_lookup mutable L1 audit L3 audit soft-delete

Standard chronic condition catalogue with ICD-10 codes for interoperability. Flyway seeds common conditions; admin can add hospital-specific entries. Referenced by patient_chronic_conditions.condition_id in Module 07.

Columns (table-specific; uniform block also present)
ColumnTypeNullConstraintDefaultComment
iduuidNOPKuuidv7()Surrogate primary key
condition_codetextNOUNIQUE, CHECK length 2–40—Short machine code in SCREAMING_SNAKE (e.g. T2DM, HYPERTENSION, ASTHMA)
condition_nametextNO——Display name shown in UI and printed on clinical documents
icd10_codetextYES——ICD-10 code for insurance / ABDM / health exchange interoperability (e.g. E11, I10)
categorytextNOCHECK IN (…)—Body system: endocrine | cardiovascular | respiratory | neurological | musculoskeletal | renal | gastrointestinal | other
descriptiontextYES——Clinical note — management guidelines, related conditions

+ the 7 uniform audit + soft-delete columns. Flyway-seeded rows have created_by = NULL.

Constraints & Indexes
  • pk_chronic_conditions_lookup — PRIMARY KEY (id)
  • uq_chronic_conditions_lookup_code — UNIQUE (condition_code)
  • chk_chronic_conditions_lookup_code_len — CHECK char_length(condition_code) BETWEEN 2 AND 40
  • chk_chronic_conditions_lookup_category — CHECK category IN ('endocrine','cardiovascular','respiratory','neurological','musculoskeletal','renal','gastrointestinal','other')
  • ix_chronic_conditions_lookup_category — INDEX (category) WHERE deleted_at IS NULL
Triggers
  • tr_chronic_conditions_lookup_bu_touch — BEFORE UPDATE → fn_touch_updated()
  • tr_chronic_conditions_lookup_au_audit — AFTER INSERT/UPDATE/DELETE → fn_audit_row()
