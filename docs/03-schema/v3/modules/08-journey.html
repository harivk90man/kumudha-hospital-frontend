1. stations mutable L1 audit L3 audit soft-delete

Registry of every physical stage a patient can be at. One row per stage. Flyway seeds all rows at deployment; the admin rarely changes this table at runtime. station_type is the machine key used in application logic and CHECK constraints; display_name is the label shown on queue boards and dashboards.

patient_states.station_id (Module 10) FKs into this table — every row in the patient state log references exactly one station here.

Columns (table-specific; uniform block also present)
ColumnTypeNullConstraintDefaultComment
iduuidNOPKuuidv7()Surrogate primary key — FK target for patient_states.station_id in Module 10
display_nametextNO——Human label shown on queue boards and dashboards (e.g. Reception, Doctor Consultation, Lab Collection)
station_typetextNOUNIQUE (partial WHERE deleted_at IS NULL), CHECK IN (…)—Machine identifier: front_desk | vitals | doctor | billing | lab_collection | lab_processing | radiology | pharmacy. One active row per type enforced by partial unique index.
display_orderintNO——Sort order for queue board columns and stage dropdown. Lower = appears first.
sla_minutesintYESCHECK > 0 when not NULL—Target minutes before patient should leave this stage. NULL = no SLA. Breached rows are flagged on the queue board.
colortextYES——CSS hex color for the queue board chip (e.g. #0d6efd). NULL = use theme default.

+ the 7 uniform audit + soft-delete columns. Flyway-seeded rows have created_by = NULL.

Constraints & Indexes
  • pk_stations — PRIMARY KEY (id)
  • chk_stations_type — CHECK station_type IN ('front_desk','vitals','doctor','billing','lab_collection','lab_processing','radiology','pharmacy')
  • uq_stations_type — UNIQUE INDEX (station_type) WHERE deleted_at IS NULL — one active station per type
  • chk_stations_sla — CHECK sla_minutes IS NULL OR sla_minutes > 0
  • ix_stations_order — INDEX (display_order) WHERE deleted_at IS NULL  — ordered stage list for dropdowns
Triggers
  • tr_stations_bu_touch — BEFORE UPDATE → fn_touch_updated()
  • tr_stations_au_audit — AFTER INSERT/UPDATE/DELETE → fn_audit_row()
